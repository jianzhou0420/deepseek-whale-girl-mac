# 🐋 WhaleBalance · кит баланса DeepSeek для macOS

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt-BR.md) · **Русский**

Девочка-кит от DeepSeek, которая живёт в углу экрана вашего Mac. В её облачке — баланс DeepSeek, расходы за сегодня и обратный отсчёт до смены пикового и непикового тарифа. Это нативная версия [виджета баланса для DSH](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) для Mac, DeepSeek Harness не нужен.

![Превью](docs/preview.png)

> Это неофициальный фанатский проект. Он не связан с DeepSeek и не одобрен компанией.

## Возможности

- **Баланс**: запрашивает баланс DeepSeek по вашему API-ключу, обновляется каждые 60 секунд и по клику на неё. Общий баланс, бонусы и пополненный баланс можно показывать отдельно.
- **Расходы за сегодня**: суммирует снижения баланса как расходы. Пополнения учитываются отдельно и никогда не отменяют расходы, а любой день можно скорректировать вручную. У каждого API-ключа своя книга учёта.
- **Окно учёта**: сегодня, последние 7 дней или вся история, с подробными записями, поиском по дате или модели и структурой расходов.
- **Пик / непик**: по будням с 9 до 12 и с 14 до 18 (по Пекину) — пиковое время; выходные и праздники Китая — непиковые весь день. Пять стилей отображения, включая живой обратный отсчёт.
- **Настраиваемые облачка**: последовательность кликов, взвешенный выбор A/B и модули текста, ссылок, случайных фраз, картинок, баланса, расходов за сегодня, статуса пика, других провайдеров и использования Codex. У каждого модуля свой размер, цвета, анимированный градиент и шрифт.
- **Уведомления**: о низком балансе и превышении дневного бюджета, с редактируемым содержимым.
- **Другие провайдеры**: 34 шаблона, включая балансы OpenRouter, Kimi, StepFun и Novita, квоты подписок Zhipu, Kimi Coding, MiniMax и OpenCode Go, а также OpenAI-совместимые шлюзы. Ключи отправляются только на официальный адрес шаблона, если вы не разрешите свой.
- **Статистика Codex**: читает локальные журналы сессий Codex и считает токены и окна подписки, без доступа к сети.
- **Нативное приложение для Mac**: перетаскивайте её куда угодно — она прилипает к краям экрана и отражается у левого края. Баланс в строке меню, запуск при входе в систему, API-ключи хранятся в Связке ключей.

Не перенесены стоимость каждого хода, звук завершения задачи, уведомления о вопросах и подтверждениях и модуль названия диалога. Они зависят от внутренних событий DeepSeek Harness, недоступных отдельному приложению.

## Установка

Нужна macOS 13 или новее. Работает на Mac с Apple Silicon и Intel.

### Способ 1: установка одной командой (рекомендуется)

Откройте «Терминал», вставьте эту строку и нажмите Return:

```bash
curl -fsSL https://raw.githubusercontent.com/jianzhou0420/deepseek-whale-girl-mac/main/install.sh | bash
```

Приложение установится в `~/Applications` и сразу запустится.

### Способ 2: скачать вручную

1. Скачайте `WhaleBalance-macOS.zip` со страницы [Releases](https://github.com/jianzhou0420/deepseek-whale-girl-mac/releases/latest) и распакуйте двойным щелчком.
2. Перетащите `WhaleBalance.app` в папку «Программы».
3. При первом запуске macOS сообщит, что не может проверить разработчика, потому что приложение не нотаризовано. Чтобы всё равно открыть его:
   - Нажмите на `WhaleBalance.app` **правой кнопкой**, выберите **Открыть** и ещё раз нажмите **Открыть**.
   - Если оно всё равно не открывается, выполните в Терминале:
     ```bash
     xattr -dr com.apple.quarantine /Applications/WhaleBalance.app
     ```

### Способ 3: собрать из исходников

Понадобится Xcode или инструменты командной строки Xcode (если их нет, выполните `xcode-select --install`).

```bash
git clone https://github.com/jianzhou0420/deepseek-whale-girl-mac.git
cd deepseek-whale-girl-mac
./build.sh
open WhaleBalance.app
```

При первом запуске откроется окно настроек. Вставьте API-ключ DeepSeek и сохраните его. Ключ хранится только в Связке ключей macOS.

## Как пользоваться

| Вы | Она |
|---|---|
| Кликаете по ней | Обновляет баланс и показывает облачко с балансом |
| Кликаете по облачку | Показывает следующий пункт (случайные фразы и картинки) и закрывается после последнего |
| Перетаскиваете | Перемещает её; при отпускании она прилипает к ближайшему краю |
| Правый клик по ней, кнопка ⋯ или 🐳 в строке меню | Меню: размер, звуки, облачка, прилипание, учёт, настройки, выход |

## Конвейер графики

`art-pipeline/` создаёт новые позы девочки-кита с помощью генерации изображений, встроенной в Codex CLI, и расходует лимит подписки ChatGPT вместо API-ключа. Он вырезает фон, чистит края, проверяет каждое изображение, перегенерирует неудачные и добавляет удачные во встроенную галерею приложения. Опишите новые позы в `art-pipeline/assets.json` и запустите:

```bash
codex login
./art.sh all
```

Одно изображение занимает около 40 секунд. Генерация изображений расходует лимиты Codex в 3–5 раз быстрее текста.

![Изображения, созданные конвейером](docs/generated-art.png)

Ищете гуляющего по рабочему столу питомца из первой версии? Он по-прежнему доступен в [релизе v0.0.1](https://github.com/jianzhou0420/deepseek-whale-girl-mac/releases/tag/v0.0.1).
