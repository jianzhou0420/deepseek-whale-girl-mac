# 🐳 DeepSeek Whale Girl · настольный питомец для Mac

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt-BR.md) · **Русский**

Девочка-кит от DeepSeek, которая живёт внизу экрана вашего Mac. Она бегает туда-сюда, следит глазами за курсором, говорит, когда вы по ней кликаете, плачет, когда вы её поднимаете, а от скуки погружается в «глубокие размышления». Иногда она поднимает табличку с иероглифом «区» и спрашивает, что значит «凶».

> Это неофициальный фанатский проект. Он не связан с DeepSeek и не одобрен компанией.

## Установка

Нужна macOS 13 или новее. Работает на Mac с Apple Silicon и Intel.

### Способ 1: установка одной командой (рекомендуется)

Откройте «Терминал», вставьте эту строку и нажмите Return:

```bash
curl -fsSL https://raw.githubusercontent.com/jianzhou0420/deepseek-whale-girl-mac/main/install.sh | bash
```

Приложение установится в `~/Applications` и сразу запустится.

### Способ 2: скачать вручную

1. Скачайте `WhaleGirl-macOS.zip` со страницы [Releases](https://github.com/jianzhou0420/deepseek-whale-girl-mac/releases/latest) и распакуйте двойным щелчком.
2. Перетащите `WhaleGirl.app` в папку «Программы».
3. При первом запуске macOS сообщит, что не может проверить разработчика, потому что приложение не нотаризовано. Чтобы всё равно открыть его:
   - Нажмите на `WhaleGirl.app` **правой кнопкой**, выберите **Открыть** и ещё раз нажмите **Открыть**.
   - Если оно всё равно не открывается, выполните в Терминале:
     ```bash
     xattr -dr com.apple.quarantine /Applications/WhaleGirl.app
     ```

### Способ 3: собрать из исходников

Понадобится Xcode или инструменты командной строки Xcode (если их нет, выполните `xcode-select --install`).

```bash
git clone https://github.com/jianzhou0420/deepseek-whale-girl-mac.git
cd deepseek-whale-girl-mac
./build.sh
open WhaleGirl.app
```

## Как с ней играть

Она говорит по-китайски. Её фразы — шутки про DeepSeek, например «服务器繁忙，请稍后再试» («Сервер занят, попробуйте позже»).

| Вы | Она |
|---|---|
| Двигаете мышь | Поворачивает голову к курсору (16 направлений) |
| Кликаете по ней | Машет рукой, подпрыгивает, что-то говорит или начинает «глубоко размышлять» |
| Перетаскиваете | Плачет «Поставь меня!» и падает на землю, когда вы её отпускаете |
| Правый клик по ней или 🐳 в строке меню | Меню: поговорить, подумать, поднять табличку, поспать, вернуться в центр, выйти |
| Ничего не делаете | Гуляет, витает в облаках, дремлет и поднимает табличку |

Она не мешает работать. Клики по прозрачной области вокруг неё проходят прямо в окно позади.

**Выход**: Нажмите 🐳 в строке меню и выберите 退出鲸鱼娘 (Выйти). У приложения нет значка в Dock, поэтому ⌘Q не работает.

**Открыть снова**: Найдите `WhaleGirl` через Spotlight (⌘ Пробел).

**Удаление**: Закройте приложение и перенесите `WhaleGirl.app` в Корзину.

## Настройте под себя

Весь код находится в одном файле — [`main.swift`](main.swift):

- Её фразы и пункты меню — в `enum Lines`.
- Какие кадры анимации использует каждое состояние — в `struct Anim`.
- Как часто она ходит, спит и говорит — в `decide()`.

После изменений снова запустите `./build.sh`.
